# 🔮 Fool Me Once

An interactive platform for Tarot card readings. Users can select 3 cards to explore their Past, Present, and Future through AI-driven interpretations.

---

## Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js.

---

## Getting Started

To launch the project, you need to run both the backend and the frontend simultaneously. Open **two separate terminals**.

### 1. Backend Setup (Server)

1. Navigate to the backend directory:

```bash
cd backend

```

2. Install the required dependencies:

```bash
npm install

```

3. Start the server:

```bash
node server.js
npm start

```

_The server will typically run on `http://localhost:5000`._

---

### 2. Frontend Setup (Client)

1. Navigate to the frontend directory:

```bash
cd frontend

```

2. Install the required dependencies:

```bash
npm install

```

3. Start the React application:

```bash
    npm run dev

```

_The website should automatically open at `http://localhost:5173/`._
